# v0.1.0-beta.5 — Self-contained Personal Model package

This beta introduces a single macOS package that contains the reviewed,
pinned Personal Model Runtime source. Installing the product no longer checks
out or downloads the Personal Model source repository.

## User-visible changes

- A new user can install the Personal Model Runtime and native Who Am I app
  from one downloaded package.
- An existing verified owner-local Personal Model is detected and connected
  without replacing its model data or repeating onboarding.
- First launch reads only the signed-in user's local Personal Model; production
  payloads contain no Cecilia, Lin, or developer Card defaults.
- The installer verifies the embedded Runtime commit, Git tree, locked files,
  and package manifest before executing it.

## Current beta constraints

- macOS 13 or newer and Xcode Command Line Tools are required.
- Runtime dependencies and the pinned private Node runtime are downloaded from
  their package distribution services during first installation. The Personal
  Model source repository itself is not contacted.
- Release status remains `HOLD` until the release checklist contains direct
  evidence and the named release owner changes it in a reviewed commit.
