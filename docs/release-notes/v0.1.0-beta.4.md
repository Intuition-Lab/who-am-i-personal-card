# v0.1.0-beta.4 — Native macOS app window

This candidate replaces the browser-opening launcher with a universal native
macOS application.

## Product changes

- `Who Am I.app` now contains a real AppKit executable and independent window.
- The existing Card UI renders inside an owner-local WKWebView; Safari, Chrome,
  and the default browser are not opened on launch.
- The app verifies the exact production Card version before loading the UI.
- The app starts the pinned private Node service when needed and terminates the
  service it owns when the app quits.
- Local navigation remains restricted to `127.0.0.1:8772`; explicit external
  links are handed to macOS.
- The installer produces one universal arm64 + x86_64 launcher and applies an
  ad-hoc signature.

## Unchanged boundaries

- The approved V5 visual design and interactions are unchanged.
- Personal Model data remains owner-local under `~/.persome`.
- Existing owner-controlled Personal Models still connect automatically.
- Cecilia and Lin remain development-only fixtures and are not installed.
- This candidate is not Developer ID signed or notarized.
- `RELEASE_STATUS` and `PILOT_STATUS` remain `HOLD`.
