# v0.1.0-beta.2 — Existing Personal Model auto-connect

This candidate preserves the current Who Am I UI while removing repeated setup
for people who already have a Personal Model on the Mac.

## Changes

- securely detects an owner-controlled standalone Runtime at
  `~/.persome/venv/bin/persome`;
- installs only Who Am I when that Runtime already exists, without replacing or
  claiming the Runtime, changing model data, repeating onboarding, or editing
  MCP client settings;
- automatically connects a ready existing Personal Model on first launch;
- migrates an existing local Who Am I profile when available and otherwise
  creates the initial Card identity from the macOS account;
- persists one stable `local-*` partition and keeps Card, Rewind, Identity,
  Connector, Report and Evidence on that same model;
- keeps the prior profile and permission flow for new or incomplete Runtime
  installations;
- adds server, setup, isolation and installer-foundation regression coverage.

The application remains an unsigned and unnotarized macOS beta. Release and
pilot invitation decisions remain `HOLD` until their evidence gates are
completed.
